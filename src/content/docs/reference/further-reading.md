Use the official documentation for exact commands. Use the communities for ideas and for seeing how other people solved a problem.

## Official Documentation

- [Proxmox VE Administration Guide](https://pve.proxmox.com/pve-docs/pve-admin-guide.html): everything Proxmox does, including storage, backups, and virtual machines.
- [Docker documentation](https://docs.docker.com/): Docker and Compose.
- [Dockhand User Manual](https://dockhand.pro/manual/): stacks, updates, and settings.
- [Heimdall documentation](https://docs.linuxserver.io/images/docker-heimdall/): the Heimdall image and its settings.
- [Beszel documentation](https://beszel.dev/guide/getting-started): adding systems and alerts.
- [Dozzle documentation](https://dozzle.dev/guide/getting-started): log viewer settings.
- [Tailscale documentation](https://tailscale.com/docs): devices, sharing, and access rules.
- [TSDProxy documentation](https://almeidapaulopt.github.io/tsdproxy/): labels and settings.
- [Debian Reference](https://www.debian.org/doc/manuals/debian-reference/): packages, the shell, and system services.

## Communities

- [r/homelab](https://www.reddit.com/r/homelab/): hardware and other people's builds.
- [r/selfhosted](https://www.reddit.com/r/selfhosted/): apps to run and how people run them.
- [Proxmox Community Forum](https://forum.proxmox.com/): search here first when Proxmox shows an error.

Community posts go out of date. Check the date and confirm commands against the project's current documentation.

## Learning Resources

- [Linux Journey](https://labex.io/linuxjourney): short lessons on the command line and Linux basics.
- [Docker Get Started](https://docs.docker.com/get-started/): Docker's own exercises on images and containers.
- [Proxmox VE video tutorials](https://www.proxmox.com/en/services/training-courses/videos/proxmox-virtual-environment): official videos of Proxmox features.
- [Awesome Selfhosted](https://awesome-selfhosted.net/): a catalog of apps you can host yourself. Check that a project is still maintained before you deploy it.
